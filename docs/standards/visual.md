# 视觉规范

[规范索引与等级](README.md) · 行为见 [interaction.md](interaction.md) · 执行容差见 [acceptance.md](acceptance.md)

原则：保留知树温和、清晰、适合长文学习的视觉方向；用统一度量实现像素级还原。以下 token 名是目标命名，不表示已经写入 CSS。本页是界面数值的唯一权威。

## VIS-001 · 单位与对齐（MUST）

“像素级”指 **CSS px**，不是屏幕物理像素。设计标注、computed style、DOMRect 均以 CSS 坐标对齐；DPR 和 Windows 缩放只改变栅格化与可用空间，不改变 token 定义。

- 全局采用 `border-box`；度量明确是外框、内容区还是可点击区域。
- 静态尺寸写语义 token；流式宽度、视口约束、选区测量 MAY 使用 `min/max/clamp/calc` 与运行时坐标。
- 不用任意负 margin、缩小字体、整体 transform 缩放掩盖溢出。图镜头允许按 VIS-012／013 连续变换卡片几何，文字及交互控件保持屏幕可读尺寸；光学修正必须有局部说明和同类组件一致性。
- 理由：物理截图像素无法直接代表布局尺寸。正例：测按钮外框及文字基线；反例：按高 DPR 截图宽度给 CSS 加倍。验收：QA-001～QA-003。

## VIS-003 · 字体与文字（MUST）

目标字体栈：`"Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei", "PingFang SC", sans-serif, "Segoe UI Emoji", "Apple Color Emoji"`。优先沿用实际 Windows Segoe UI 路径并补足中文回退；当前 CSS 首位 Inter 未由本规范承诺供应。基准机记录实际使用字体，不以字体名声明代替已加载证据。

| 角色 | 字号／行高 | 字重 | 场景 |
| --- | --- | --- | --- |
| 表单／操作正文 | 14px / 22px | 400 | 输入、按钮、导航标题、普通说明 |
| 阅读正文 | 16px / 28px | 400 | 消息、选区全文、引用快照 |
| 辅助文字 | 12px / 20px | 400 | 标签、状态、错误、品牌副标、底栏 |
| 分组标题 | 16px / 24px | 600 | 设置小节 |
| 弹窗标题 | 18px / 28px | 600 | 普通／确认弹窗 |
| 页面标题 | 24px / 32px | 600 | 桌面主题标题 |
| 窄屏页面标题 | 20px / 28px | 600 | 窄屏主题标题 |
| 品牌名称 | 28px / 36px | 600 | “知树”；字距 2px，副标字距 0 |
| 代码 | 14px / 22px | 400 | `Consolas, "Cascadia Mono", monospace` |

所有可读文本的最终屏幕字号不低于 12px；不要通过 transform 缩字适配内容。图中按 VIS-013 降低语义细节，保持屏幕字阶。表单与辅助字阶借鉴固定行高方法；阅读正文单独留足长文空间。中英文混排正常断词，中文按自然行折行；长 URL 用 `overflow-wrap:anywhere`，代码和公式仅在自身容器横向滚动。

正例：完整字段标签、可展开全文、错误自然增高；反例：为塞入长错误而降字号或截成不可解释的省略号。操作按钮不得裁切动作词。验收：QA-002、QA-004。

## VIS-004 · 间距、边框与圆角（MUST）

- 间距基数为 4px，主要节奏为 8px；标准集合为 **0 / 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64px**。token 按 `--space-N` 命名，N 即数值。
- 20px 是知树为现有消息内边距与阅读节奏保留的自定义档，不宣称来自 TDesign 标准集合。边框、图标笔画、焦点环不受间距集合限制。
- 普通控件圆角 8px；消息／引用／编辑框外壳 12px；桌面 dialog 16px；工具栏／通知 12px。
- 普通边框 1px；引用竖线 3px；焦点环 3px、外偏移 3px，不占布局空间。
- 浮层阴影 `0 6px 24px #25244330`；dialog 阴影 `0 24px 80px #25244330`。静态消息不用浮层阴影。

理由：减少接近但不一致的局部值。正例：字段组间用标准间距；反例：每个面板各定一种圆角。验收：QA-002。

## VIS-005 · 页面骨架与响应式（MUST）

本节定义普通阅读布局及图中胶囊正文排版。图形工作区采用 VIS-012 的同画布空间与导航占位；本节消息字阶、内边距和编辑区保护继续适用，不将整张图限制在阅读列宽内。

| 区域 | 桌面：视口宽度 >700px | 窄屏：视口宽度 ≤700px |
| --- | --- | --- |
| 侧栏 | 宽 248px；内边距 24px 16px；组间 16px | 抽屉宽 `min(300px, 85vw)`；关闭不占内容宽度 |
| 顶栏 | 默认高 64px；左右 24px；控件间 8px | 默认高 64px；左右 12px；控件间 4px |
| 阅读区 | 最大列宽 840px；最小左右留白 24px；上下 24px | 左右 12px；上下 16px |
| 消息／引用 | 外间距上下 20px；内边距 20px | 外间距上下 20px；内边距 16px |
| 消息元信息 | 与正文间 12px | 同桌面 |
| 编辑区外壳 | 左右对齐阅读列；上下 12px | 左右 12px；上下 8px |
| 编辑框内部 | padding 12px；草稿最小高 68px、最大 24dvh | 同桌面 |
| 编辑区总高度 | 最大 46dvh，超出内部滚动 | 同桌面，并响应可视视口变化 |

840px 指消息外框所在列，不含两侧安全边距和滚动条槽；实际宽度为剩余空间约束后的值。页面用 `100dvh`；顶栏和底部区域不随消息滚动，`flex-shrink:0`；中间滚动子项 `min-height:0`，横向弹性子项 `min-width:0`。放大文字时顶栏 MAY 自然增高或重排，不能压缩控件。

主题树与消息区分别滚动；正文尾部不能被固定编辑框遮挡。不要把整个页面滚到底部当作消息定位方案。默认顶栏长主题可省略，主阅读标题须完整折行。断点两侧不可残留遮罩或挤出横向页面滚动。

桌面宿主当前 `min_size=(900, 600)` 是原生窗口约束，并非 Web 内容视口保证；标题栏、边框和缩放会减少实际 CSS 可用面积。具体测试窗口与内容测量按 QA-001 执行。

## VIS-006 · 控件度量与状态（MUST）

| 组件 | 目标外框／排布 | 状态要求 |
| --- | --- | --- |
| 默认按钮 | 最小高 40px；左右 padding 16px；文字／图标间 8px | 默认、hover、active、focus-visible、disabled、busy 不改变边框厚度 |
| 图标按钮 | 40px × 40px；居中 | 图形与命中范围分离，不随 flex 收缩 |
| 粗指针或窄屏按钮 | 命中区域至少 44px × 44px；图标按钮 44px × 44px | `pointer:coarse` 同样适用，不能只靠窄屏媒体查询 |
| 图标 | 默认 20px；紧凑辅助 16px；viewBox 24；笔画 1.7 | 同功能图标不混用 emoji；图标缩小不缩命中区 |
| 单行输入／select | 最小高 44px；左右 padding 12px | 各状态外框稳定；焦点用环，错误用错误边框与文字 |
| 字段组 | 标签→控件→提示／错误，间隔各 8px；组间 16px | 标签顶置；辅助区最小 20px，可自然增高 |
| textarea | 表单最小高 88px；padding 12px；可纵向扩展 | 草稿采用 VIS-005 专用高度；不限制错误文本高度 |
| checkbox | 图形 18px；与文案间 8px | 整个 label 可点击；粗指针命中区域按本表要求 |
| 主题行 | 最小高 44px；padding 8px；标题可折行 | 更多按钮固定命中宽度；标题占剩余空间 |

普通按钮使用 surface／text／control-border；主按钮使用 brand／inverse；危险确认使用 error／inverse，hover 与按下使用对应 error token；普通危险入口使用 error 文字。只读输入仍可选取文本；禁用样式用 disabled token；错误不得只靠颜色。

busy 保持原按钮占位，长文案 MAY 增高而不可裁切；同组按钮换行时保持动作顺序。正例：发送加载时不推挤旁边按钮；反例：设置错误后保存按钮掉到不可达区域。验收：QA-002～QA-004。

## VIS-007 · 对话框（MUST）

- 桌面普通宽 `min(640px, calc(100vw - 40px))`，确认宽 `min(440px, calc(100vw - 40px))`；最大高 `90dvh`，居中。
- 窄屏占可视区域全宽／全高，无外 margin、圆角为 0；软键盘出现后按可视区域约束，不把关闭或确认推到键盘后。
- 标题区与操作区 padding 为 16px 24px；正文 padding 为 16px 24px 24px；窄屏左右统一 16px，标题／操作区上下 12px。
- 采用纵向布局：标题／操作区 `flex-shrink:0`，正文 `min-height:0; overflow:auto`。长表单、嵌套确认及错误信息均不能使头尾不可达。
- 操作间隔 8px，取消在前、确认在后；空间不足可换行或纵向铺满。正文与动作区之间使用装饰分割线。

理由：长内容不应改变关闭和完成任务的位置。正例：正文内部滚动；反例：只给标题 sticky，却让确认按钮在长 fieldset 外不可见。语义见 INT-002，验收见 QA-004。

## VIS-008 · 选区工具栏与层级（MUST）

工具栏 padding 8px、操作间隔 8px；与选区偏移 8px、与可视区域边缘安全距离 8px。控件尺寸沿用 VIS-006。禁止以固定页面底部坐标放置它。

定位算法：先测量实际工具栏宽高 `w/h` 和选区矩形；取 `visualViewport`（不可用时取窗口）与消息滚动区的可见交集为边界 `B`。所有矩形先统一为 fixed 元素的布局视口坐标，计入 visualViewport 的 offsetLeft／offsetTop，不混用页面滚动坐标。首选选区上方，空间不足改下方。横向以选区中心对齐，最终将 x/y 限制在 `[B.left+g, B.right-g-w]`／`[B.top+g, B.bottom-g-h]`，其中 `g` 为上述安全距离。若区间无解，先约束宽度并重排；仍放不下则隐藏浮层并保留消息操作入口，不生成负尺寸。内容变化后重新测量，不能永久用猜测宽度。

| 层 | 层级 |
| --- | --- |
| 普通内容 | auto／0 |
| 局部 sticky 操作／标题 | 1／2，仅限组件内部 |
| 选区工具栏 | 15 |
| 通知／撤销 | 20 |
| 移动导航遮罩／侧栏 | 30／31 |
| 跳过导航链接 | 40 |
| `dialog.showModal()` | 浏览器 top layer；不是靠更大 z-index 模拟 |

普通通知距底部 16px；普通撤销条距底部 72px；左右至少 16px；长通知自然增高并与撤销条重排避免重叠。图移除恢复浮窗采用 VIS-014 的局部锚定与屏幕约束，层级仍为本表通知／撤销层。模态内反馈放在模态内，不能指望普通 toast 盖住 top layer。选区工具栏显示与恢复行为见 INT-006；验收见 QA-004。

## VIS-009 · 动效（SHOULD；减少动效支持 MUST）

轻量颜色／透明度反馈 120ms，抽屉／弹窗过渡 180ms，缓动 `ease-out`；图镜头使用 VIS-014 的专用参数。避免 `transition:all` 和影响阅读位置的装饰移动；流式文字不逐字飞入。`prefers-reduced-motion:reduce` 下关闭位移动画与平滑滚动，状态直接到位。验收：QA-002、QA-004。

## VIS-010 · 数值来源及迁移对照

本表用于识别差距，不是第二套可任选标准；目标以上述规则为准。

| 项 | 当前／外部参考 | 本规范决策 |
| --- | --- | --- |
| 品牌 | 知树暖白 `#faf9f6`、靛蓝 `#4e50a8`；TDesign 蓝 `#0052d9` | 保留知树品牌 |
| 侧栏／断点 | 当前 248px／700px；TDesign 默认展开 232px、收起 64px、切换 992px | 保留知树 248px／700px；不引入收起轨道 |

## VIS-011 · 星空树视觉语义（MUST，图形迭代目标）

极简画面以暖白、克制靛蓝、细线和留白为主：稀疏主题像星点，真实分支像树脉，胶囊是展开阅读的一颗星。当前主题、祖先路径和近邻形成层次。以下为知树自定目标 token，尚未写入 CSS。

| token／角色 | 目标映射／要求 |
| --- | --- |
| `--graph-bg` / `--graph-node-fill` | `--color-bg` / `--color-surface` |
| `--graph-node-border` / `--graph-label` | `--color-control-border` / `--color-text`；节点边界承担识别，不用装饰 line 色替代 |
| `--graph-active` / `--graph-active-fill` | `--color-brand` / `--color-selected-bg`；当前分支另有“当前”标记 |
| `--graph-parent-edge` | `--color-muted`，实线及由来方向；当前祖先路径用 active 色与线宽区分 |
| `--graph-reference-edge` / `--graph-contact-edge` | `--color-brand` / `--color-muted`；引用为有向虚线，联系为点线，选中关系显示类型与端点文字 |
| `--graph-focus-ring` | `--color-focus`；尺寸复用 VIS-004，与当前活动状态可同时辨认 |
| `--graph-erase-preview` | `--color-error`；划删轨迹、目标轮廓配主题名和动作文字，不仅凭颜色 |

胶囊外框圆角 24px，内部消息沿用 VIS-004。可用当前节点静态淡光晕辅助定位；根与其他节点不默认持续发光，星空主题不依赖暗色背景、闪烁或粒子。非焦点对象通过层级、线型和低细节减少干扰，不整体降低可操作节点透明度损害对比度。只读保留文字／图标状态及可见焦点。必要边界、标签、路径按 QA-003 实测；验收：QA-010。

## VIS-012 · 同画布空间与专注胶囊（MUST，图形迭代目标）

可用工作区 U 是 visualViewport 与画布的可见交集，扣除顶栏、已占位工具带、安全区及软键盘遮挡；不以浏览器外框或屏幕分辨率计算。以下为初始设计目标，须实测校准。

| 区域 | 目标 |
| --- | --- |
| 图模式导航 | VIS-005 抽屉尺寸，默认不占常驻侧栏；顶栏沿用 VIS-005，文字放大后允许重排 |
| Focus 胶囊 | 宽、高默认分别为 U 的 90%，用户可在 88%～92% 间选择；不触发浏览器 Fullscreen API |
| 探索边缘 | 四周至少 24px；尺寸为 `min(用户占比 × U 尺寸, U 尺寸 − 48px)`，受限视口可低于目标占比，以控件可达优先 |
| 专注正文 | 阅读列沿用 VIS-005 并在胶囊内居中，字阶沿用 VIS-003，编辑区不遮正文 |
| Peek | 相对进入前 Focus 的几何倍率默认 0.62，可在 0.45～0.75 调整；当前主题保留空间中心线索，显露有界邻域 |
| Overview | 沿用进入前镜头；用户平移、缩放或主动适配邻域，不按消息条数自动缩小 |
| 非专注编辑托盘 | 活动输入沿屏幕层底边定位，宽不超过 VIS-005 阅读列上限，边缘至少 16px；保留输入、发送与主题名，内部按可用高度滚动 |
| 关系检查浮层 | 最大宽 `min(360px, U.width − 32px)`；不足时转为屏幕内非模态关系页，保留关闭与返回 |

卡片中心、外框与边端点使用同一 camera 变换，保持同比例空间连续性。输入及工具栏在屏幕层连续定位，以可读字号和命中尺寸布局，不随几何倍率缩成小控件。Focus 占比与 resize 不改写世界坐标。

宽窄屏使用同一状态模型；狭小屏幕可只呈现当前胶囊及概览入口，用显式导航查看邻域。文字放大、软键盘和长错误导致空间不足时重排控件并内部滚动，发送／返回始终可达。布局变化按 INT-013 保留草稿、镜头和阅读锚点。

图内部层序为背景→边→节点外框→文字与编辑层→焦点／预览；工具栏、恢复浮窗及模态层级按 VIS-008。验收：QA-010。

## VIS-013 · 节点、标签与语义缩放层级（MUST，初始实验目标）

scale 为图坐标到屏幕 CSS 坐标的无量纲倍数，与 DPR／浏览器缩放无关。对话增加时，胶囊保持视口约束、正文内部分页／滚动；镜头拉远时降低内容密度，不把全部历史缩入一张卡片。

| token／度量 | 目标值／计算方式 |
| --- | --- |
| `--graph-scale-min` / `--graph-scale-max` | 0.25 / 2；缩放、适配及恢复镜头均限制有效 scale，装不下时聚合 |
| `--graph-scale-default` / `--graph-scale-step` | 1 / 1.2；按钮每次乘／除步长后 clamp 到有效区间 |
| `--graph-node-dot` | 普通 12px、根／聚合 16px、活动 20px，均为屏幕空间；类型仍有标签 |
| `--graph-node-hit` | 节点／展开控件／连接柄至少 44×44px 屏幕命中框，所有指针适用；碰撞计入命中范围，拥挤时聚合或候选选择 |
| `--graph-label-font` | 至少 12px／20px，屏幕空间，继承 VIS-003 字体 |
| `--graph-label-width` / `--graph-label-gap` | 常规标签最大宽 160px、两行，距外缘 8px；可点击／聚焦获取全文 |
| `--graph-edge-width` / `--graph-path-width` | 普通 1.5px／活动主路径 2.5px，屏幕空间；线型、方向及可访问名称同时存在 |

细节层级以变换后的可用正文／标题框尺寸和全局预算共同决定：

| 层级 | 条件与呈现 | 屏幕字阶 |
| --- | --- | --- |
| L3 完整对话 | 当前活动 Focus 胶囊，分页正文与稳定编辑器 | 阅读正文沿用 VIS-003 |
| L2 原文预览 | Peek／Overview 可用正文框至少 240×144px，且在预览预算内 | 标题 16px／24px，摘录 14px／22px |
| L1 主题 | 标题框至少 120×44px，且在标签预算内；显示标题、类型及必要状态 | 至少 12px／20px，最多两行 |
| L0 聚合 | 投影尺寸不足、过密或超预算 | 星点／聚合数量及必要标签，不继续堆叠小字 |

L2 取当前阅读轮次的主题标题及前两段非空原文，优先各取问题与回答一段；其他主题取最近一轮已持久化问答。每段最多两行，字符预算见 CODE-011，截断有省略号及打开原文入口。代码／公式用安全原文摘录，不强制重渲染；无内容标“暂无对话”，失败有重试。活动 partial 不缓存为其他节点的已完成摘录。

降级优先于缩字。升档需超过该档尺寸门槛 10%，降档低于门槛才触发；同一手势中优先序稳定，避免闪烁。用户可选“仅标题／自动细节”，不突破最小字阶及预算。

过渡可使用不承接选择／编辑的轻量几何或内容代理，停稳按对应屏幕字阶排版；活动输入始终为真实稳定控件，不以截图替代可访问正文，降低细节仍保留列表和焦点语义。

优先级为键盘焦点／活动主题→所选关系端点→祖先路径→直接邻域→其他。超出标签预算的选中集显示数量并用有界列表检查，不强行画出所有标签。数量上限见 CODE-011；布局遵循真实主树，跨边不改变归属。验收：QA-010。

## VIS-014 · 手感、阈值、恢复浮窗与辅助显示（MUST，图形迭代目标）

| 参数 | 初始值与解释 |
| --- | --- |
| 长按 | 350ms，按下点最大位移 6px；超过则取消本次长按资格 |
| 拖动阈值 | 8px，适用于平移、移位和连接柄；长按已激活后的框选直接跟随 |
| 右键划删阈值 | 累积路径至少 24px，且离按下点最大距离至少 8px；避免原地抖动 |
| 自动 Peek | 越过胶囊外边界 12px 后停留 240ms；移出应用窗口不算探索 |
| 返回 Focus | 进入胶囊边界向内 12px 后停留 150ms，仅对未锁定 Peek 生效 |
| 最近输入保护 | 最后键入后 800ms 内冻结自动镜头；IME 全程冻结，解除后重新计停留 |
| 镜头过渡 | 280ms，`cubic-bezier(.2,.8,.2,1)`；从当前值接续，无弹簧回摆及排队补播 |
| 手势反馈 | 随指针逐帧更新，普通颜色反馈沿用 VIS-009 |
| 减少动效 | 镜头时长 0，直接到相同终态；显式拖动直接跟随 |

胶囊边界按屏幕投影计算，向内／外安全带形成回差。邻接工具栏、输入托盘、滚动条及恢复浮窗属于交互保护区域，经过它们不误判为离开。胶囊动画经过静止指针不重新触发往返；需新的真实指针移动及完整停留。

恢复浮窗初始取释放时目标外框上方 8px，不足改下方；使用屏幕坐标，距 U 边缘至少 16px。按实测尺寸 clamp 并允许换行，最大宽 `min(360px, U.width − 32px)`。显示后固定于屏幕，轻量标记可指向原世界坐标；平移不把恢复按钮带出视野，resize 后重新约束。

恢复按钮命中至少 44×44px，浮窗避让活动输入、发送和当前手势目标，冲突时放到 U 顶部安全位。一次一个主浮窗，其他记录收纳到“最近移除（N）”。普通 toast 可短时消退，恢复入口按关闭、成功恢复或服务器到期改变；关闭浮窗后列表仍在，倒计时不持续播报。

forced-colors 使用系统 Canvas、CanvasText、Highlight，取消光晕和透明叠层，保留线型、方向、当前标记及焦点；图与列表对象名称、关系类型和加载状态一致。验收：QA-003、QA-010。
