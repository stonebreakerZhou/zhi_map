# 交互规范

[规范索引与等级](README.md) · 外观只引用 [VIS 规则](visual.md) · 验证步骤见 [QA 规则](acceptance.md)

原则：用户知道正在操作哪个对象、是否已经保存、失败后如何继续。下面约束行为；具体尺寸、颜色与定位数值均以视觉规范为准。

## INT-001 · 操作层级与统一状态（MUST）

一个独立任务上下文最多一个主要动作；设置表单、导航新建、当前消息编辑区是不同上下文，不能据此强制整个应用只剩一个主按钮。TDesign 的主次按钮原则在此按任务应用。

| 状态 | 必须提供的反馈／操作 | 禁止示例 |
| --- | --- | --- |
| 初始加载 | 明确正在加载哪部分，避免旧数据被误认为当前数据 | 空白面板被当作无配置 |
| 空状态 | 说明没有数据／没有搜索结果，给出创建或清除筛选入口 | 把请求失败写成“没有主题” |
| 操作中 | 按任务禁用重复提交，保留相关输入及可安全取消路径 | 双击生成重复主题／重复请求 |
| 成功 | 以服务端结果或真实浏览器操作结果确认 | 点击即显示“已保存／已复制” |
| 可恢复失败 | 说明失败阶段、保留输入、就地重试 | 全页刷新清空用户输入 |
| 断开连接 | 与空状态区分；提供重连／重试，不宣称模型完成 | 将流 EOF 当成功 |

短状态用 `role=status`，需要及时处理的错误用 `role=alert`；避免流式逐字播报轰炸读屏。加载与反馈不抢走用户输入焦点。正例：“配置已保存，但连接测试失败”；反例：“失败”而未说明保存结果。验收：QA-004、QA-005。

## INT-002 · 对话框、关闭与未保存修改（MUST）

- 打开时焦点进入合理首项：编辑任务进入主要输入，危险确认优先取消或说明；Tab／Shift+Tab 限制在当前模态内。
- 取消、关闭按钮、Escape 走同一关闭判断；dirty 时先确认“放弃未保存的修改？”，拒绝放弃回到原表单，已输入内容不变。
- 不把点击遮罩默认当提交或放弃；当前原生 dialog 保持显式关闭。嵌套确认只关闭自身对应层。
- 不可取消的提交阶段锁定关闭并说明处理中；不可永久 busy。支持取消的任务提供独立取消动作，不把“关窗口”冒充已取消。
- 关闭后返回原触发元素；元素已删除时返回逻辑相邻操作或输入框。成功切换任务时焦点进入新任务，不强行回到已消失的按钮。
- 表单 Enter 可提交单行输入，但 `isComposing` 时不得触发；多行文本 Enter 保持换行，快捷发送另有清晰说明。

理由：关闭与提交都是用户意图，不应隐式丢输入。正例：重命名输入中文候选时 Enter 只完成组词；反例：候选词未确认就重命名。验收：QA-004。

## INT-003 · 模型配置（MUST）

| 场景 | 规则与正例 | 反例 |
| --- | --- | --- |
| 自动加载 | 打开后读取生效配置；加载完成前禁用编辑；失败显示重新加载 | 用空默认表单覆盖已保存配置 |
| 默认值 | 未配置时模型留空，显示尚未配置；协议／地址默认值不代表模型可用 | 自动把示例模型当已验证账号能力 |
| 服务商预设 | 明示替换协议、地址、模型；预设仅填写示例 | 把兼容预设描述为独立协议或实时目录 |
| 自定义与 dirty | 表单与已保存基线比较；输入密钥也算 dirty；切协议保留自定义地址，选品牌预设才明确替换 | 使用任意字段变化直接刷新服务端配置覆盖草稿 |
| 连接身份变化 | 更改协议或地址时先清空本次密钥并关闭明文显示，再更新连接；新连接必须输入对应密钥 | 将旧服务密钥带到新服务 |
| 保留密钥 | 仅同一已保存个人连接允许留空保留；回读不返回密钥 | placeholder 展示旧 key 后几位却实际泄露原值 |
| 保存并测试 | 先保存当前表单，再测试；测试前提示短请求可能产生用量 | 用服务端旧配置测试当前未保存表单 |
| 部分成功 | 保存成功即更新基线并清本次密钥；测试失败明示保存仍成功，允许重试测试 | 将部分成功显示为全部失败或悄悄回滚 |
| 清除个人配置 | 二次确认说明删除个人密钥与参数、放弃本次修改、回退服务器配置；刷新实际生效状态 | 暗示会删除会话和消息，或宣称回退一定存在 |
| 并发与过期响应 | 卸载、重开、切换加载请求后忽略旧响应；重试不与保存交错覆盖新表单 | 第一次慢加载覆盖第二次已编辑内容 |

数值输入前后端一致：超时为 CODE-004 合法整数范围，输出上限为合法整数，temperature 可留空；空字符串不能悄悄变成零，空白模型／空白密钥不得通过。非法 URL、越界、非整数和非有限数给字段级原因，关联 `aria-invalid`／`aria-describedby`，提交时定位首个错误。

**验收例**：打开慢加载设置→关闭→重开→成功加载并修改→旧请求返回，输入仍是新值；保存成功后模拟测试断开，重新打开仍能看到已保存参数。见 QA-004、QA-005。

## INT-004 · 新建、导航与整理（MUST）

- “新的学习问题”有同步防重保护；当前已是无内容、无草稿的默认根主题时复用，不能连点制造空主题。
- 新建成功聚焦草稿；窄屏完成新建或切换后收起导航。仅打开“更多”不应误切当前阅读主题。
- “更多”绑定被点击行的稳定 ID；对非当前主题重命名、收藏、删除，确认文案和命令必须指向该行，而非 controller 当前活动对象。
- 切换前 flush 草稿；失败保留当前主题与草稿并提示重试。迟到的页面响应不改变较新导航结果。
- 搜索变化重置分页位置；区分搜索无结果与加载错误；清除搜索恢复列表入口。
- 重命名去除首尾空白，空标题阻止保存；中文 IME 遵循 INT-002。收藏即时结果与尚未保存的标题修改分别反馈。

理由：对象正确性优先于“操作有响应”。正例：正在读 A，从 B 的更多菜单重命名 B；反例：B 菜单删除 A。验收：QA-004、QA-005。

## INT-005 · 删除与撤销（MUST）

### 当前实现与目标边界

**当前旧契约**：现有 branch-delete undo 为单次撤销，最长十分钟，且仅在下一次持久化工作区 mutation 前有效；草稿保存也使其失效。时间到／revision 变化须撤去旧撤销入口并解释原因；前端先 flush，有待存草稿时不能承诺旧撤销仍可用。这是迁移前的能力限制，不是新图恢复目标。

**图形迭代目标**：图手势与主题菜单共同迁移到逐操作软移除／恢复契约，服务端保存独立 operation 记录。旧端点在迁移前按实际能力标示，不能接到新“恢复”入口。CODE-004 的工作区 revision 校验继续约束现有命令，新移除／恢复采用 CODE-012 的目标版本与依赖冲突检查。

### 移除范围与提交

目标“移除主题／分支”将该主题及其消息从正常工作区移入可恢复 tombstone。独立子分支继续存在，解除指向被移除父节点的归属并成为独立根，保留原有出处快照、说明来源已移除。现有引用快照可读，来源导航显示失效。根主题同样可移除；聚合标记不是主题，只能展开／收起。

| 动作 | 确认及完成语义 |
| --- | --- |
| 菜单移除单主题 | 菜单点名主题，说明“可恢复，独立子分支保留”；与划删共用恢复契约 |
| 单主题右键划删 | INT-015 预览明确目标，释放提交软移除；正常单次划删无需额外模态确认 |
| 显式多选移除 | 先选择，再查看“移除所选”的名称、数量与范围并确认；明确目标集原子提交 |
| 恢复主题 | 自软移除提交成功起十分钟内按操作恢复，以服务器 expiresAt 为准 |
| 删除整个会话主线 | 独立危险动作、点名主线并额外确认；说明主线及消息永久删除、独立子分支保留且不可恢复；划删不触发此动作 |
| 删除后活动对象 | 使用服务端返回的有效活动主题；没有主题进入可新建空状态，不保留失效标题 |

- 释放后进入“正在移除”，可保留淡化占位；只有服务端确认持久化，才移除正式节点并显示成功浮窗。
- 活动主题未保存草稿必须纳入恢复内容；无法可靠保存则阻止移除、保留输入并允许重试。存在对应 run 时先停止并完成终态协调，再提交移除；与回答完成的竞态须确定唯一结果，其他主题的 run 继续。恢复不重启 run 或重新发送。
- 失败恢复节点可操作状态，就地显示原因／重试；结果未知显示“正在核实”，按同一 operation ID 查询，不重复发起新删除操作。
- 提交前可取消；请求已发出后的取消必须核实服务端结果，已提交则提供恢复，不把客户端 abort 描述为回滚。

### 恢复入口与冲突

- 成功浮窗显示 **“已移除「主题」　恢复”**，初始锚定移除位置附近，定位见 VIS-014；多选显示数量并可查名称。
- 平移、缩放、焦点、选择、分页和 LOD 变化不关闭恢复能力；其他草稿保存、发送／完成问答、重读及无关关系写入也不使记录失效。
- 浮窗可关闭；“最近移除”常驻工具入口保留有效记录、剩余时间与恢复按钮，刷新后可重新读取。连续移除合并为一个主浮窗，显示最新操作和其他可恢复操作数，不堆叠弹窗。
- 恢复仅还原该操作拥有的主题、消息、草稿及仍满足前置条件的关系，不回滚工作区。不同 ID 的同名主题保持独立；原 ID 被占用、关系依赖已变更或父节点再次移除须返回具体冲突，不消耗未过期记录。
- 若提供“仅恢复主题和消息、作为独立根”，须预览变化并由用户确认补偿命令，不能覆盖后续关系、输入或回答。恢复成功重新呈现并高亮主题，用户点击“打开”才切换当前对话。
- 到期说明“恢复期限已过”并撤去恢复按钮；后台清理时机不延长期限。永久删除与真实不可恢复的未保存内容处置使用相应危险确认。

危险确认使用“永久删除会话”等动作词，并采用 VIS-006 危险样式。验收：QA-004、QA-005、QA-010；分别验证当前限制和目标恢复，不以旧撤销通过证明新能力已实现。

## INT-006 · 精确选区、复制与展开（MUST）

- 鼠标、触摸与键盘选区等价；仅单条消息内有效选区显示操作。跨消息或不支持的排版选区不得退化为整条正文。
- 公式提供“选择原文”入口；原文视图使用真实源文本，不把渲染后的数学符号猜回源表达式。
- 选中文字仅显示工具栏，不自动建分支；“展开讨论”与“从这里分叉”均进入原文预览，后者预选整条消息。
- 预览显示精确原文、背景选择和问题输入；背景截止选区末尾，不包含后续消息。取消背景仍保留选区；用户确认后才创建讨论。
- 复制使用已校验源文本的精确片段，偏移遵循 CODE-003；不复制隐藏按钮、Markdown 渲染附加内容。仅 Clipboard Promise 成功后报成功；权限拒绝提示系统复制菜单或快捷键。
- 指针按下工具栏不能丢掉选区；键盘能访问工具栏及其命名控件。点击外部、Escape、切主题／页、打开模态时隐藏；滚动／resize 后重新定位，选区离开可视区时隐藏。
- 取消预览恢复原选区和合理阅读位置；原 DOM 已消失时不向失效节点写 Range。返回原文按 ID 加载相应页后定位选区，不意外滚到整页底部。

正例：选中含 emoji 的中文原文，复制与预览逐字符相同；反例：框选失败后默认扩展整条消息。定位只按 VIS-008；验收：QA-004、QA-005。

## INT-007 · 分页、引用与背景（MUST）

- 主题、消息、来源、引用、背景使用服务端分页；界面显示加载状态，防止重复翻页；旧页可暂留但明确标为加载中，不能操作错误对象。
- 页加载失败保留阅读位置与选择，提供就地重试；空页、末页、错误状态分别显示。
- 引用跨消息页保留已选项；切来源清空旧来源选择并明确说明，不能把不同来源的 range 混合提交。
- range 显示源文本区间，合法性与代理对边界按 CODE-003 检查；已删除、重复、自引用、越界来源拒绝并提示重新选择。
- “返回原文”定位来源消息与区间；来源已删时说明无法返回，现有引用快照仍可读。
- 背景全选用 scope 表达；限额和上下文预算引用 CODE-005，不假装客户端已下载全量历史。
- 模型上下文裁剪要明确告诉用户范围和原因；完整历史仍可分页查看，必需选区或问题超预算时阻止生成并解释，不静默删掉它们。

正例：引用翻页后选中项仍在，切来源后清空；反例：仅把当前页勾选当全部。验收：QA-004～QA-006。

## INT-008 · 发送、流式生成与恢复（MUST）

发送前保存草稿；未配置模型给设置入口；历史关联提示由用户明确决定是否引用，不偷偷带入其他会话。发送中按分支控制防重，其他主题可按并发预算继续使用。

| 阶段 | 用户可观察结果 |
| --- | --- |
| started | 展示该分支正在生成，必要时展示上下文裁剪说明 |
| delta／usage | 增量文本仅属于对应 run；usage 不是完成信号，不伪造用量 |
| completed | 仅后端确认持久化的成功终态才显示完成，刷新受影响页 |
| failed／意外断开 | 保留已提交问题并给重试路径；partial 不冒充完整历史消息 |
| cancelled | 显示已停止，不报成功；取消具体 run，不取消别的分支 |

迟到 run／乱序事件按 CODE-004 拒绝；后台完成不切换前台主题，不覆盖当前草稿。停止后是否保留临时预览须明确标注未完成；当前实现会清运行态 partial，不能宣称已持久保存半截回答。重试回草稿时保留问题与用户后续输入。验收：QA-005。

## INT-009 · 数据导入与导出（MUST，部分为待实现目标）

- 导入前明确文件、格式、将替换当前工作区的范围与不可隐式合并的语义；确认覆盖，保护未保存草稿。取消文件选择无副作用。
- 上传／校验阶段显示进度或真实阶段，不编造百分比；提供显式取消。取消须传递到服务端暂存任务，原工作区不变。
- 最终原子提交阶段若不能取消，明确进入提交中并锁定取消；若取消与提交竞态，查询最终状态后说明“已取消”或“已导入”，不能仅凭前端 AbortError 宣称回滚。
- 导入成功再清缓存并重新加载；若已提交但刷新失败，提示“已导入，刷新失败”，重试刷新，不要求重复导入。
- 失败解释格式、限额或版本冲突，并保留原工作区；当前卸载 abort 不等同于已具备上述完整取消体验。
- 导出不含模型配置；仅下载请求开始不代表文件已落盘，遵守浏览器下载语义，不无依据提示“备份已保存”。

理由：传输状态和持久化结果不同。验收：QA-005、QA-007。

## INT-010 · 键盘与可访问名称（MUST）

交互元素采用原生 button、input、select、label 与 dialog；图标按钮有动作名称，输入有持久可见标签，错误与提示可关联读出。当前导航项使用 `aria-current`，切换型按钮使用 `aria-pressed`，busy 状态可感知。

键盘顺序与阅读／任务顺序一致，焦点可见、不被遮挡；支持跳过导航到主内容。无悬浮也能发现关键操作；触摸无需 hover。正例：“复制选中文字”可被读屏命名；反例：只有无名称 SVG 的 click handler。验收：QA-004。

## INT-011 · 原生星空树的对象与关系（MUST，图形迭代目标）

星空树是 AI 对话与分支的原生主视图。用户在同一画布找到问题、展开胶囊阅读、产生讨论并沿出处返回；对象语义唯一如下，确认边界见索引。

| 对象 | 代表什么／允许行为 |
| --- | --- |
| 主题／讨论分支节点 | 使用现有领域稳定 ID 表示可继续提问的讨论单元；根与子讨论用层级及类型区别 |
| 对话胶囊 | 同一节点在专注时的展开形态，包含标题、出处、分页正文、输入与发送；随同画布镜头连续变形，保持同一消息与编辑状态 |
| 消息与原文摘录 | 消息归属于主题；预览从原文截取并标示“原文摘录”，不是 AI 摘要，不把每轮问答自动建立为图节点 |
| 选区 anchor | 关系的出处：来源分支、消息 ID、精确 range 及必要快照；不自动成为独立讨论节点。创建讨论须先完成 INT-006 预览确认 |
| 主树 parent 边 | 表示分支由来，根可多个；每节点至多一个 parent，整体为无环森林。主路径是当前分支到所属根的祖先链，不按空间远近推断 |
| 跨主题边 | 显式区分有方向的“引用”和可无向的“联系”；可跨主树，整体可能形成多节点环。显示类型和可查出处；不能借跨边重写 parent |
| 聚合标记 | 有界展示的数量汇总，可展开、分页或搜索；不可发送、连线或当作真实主题移除 |

**视觉关系不等于 AI 上下文**：邻近、镜头、框选、主路径或联系线均不加入模型输入。“引用”须经过选源／range／背景确认，预算及裁剪按 INT-007、CODE-005。提供鼠标可打开的“本次上下文”入口查看实际生效范围。验收：QA-010。

## INT-012 · 连续镜头、探索与单活动焦点（MUST，图形迭代目标）

### 状态转换

始终只有一个活动对话分支。camera/view 状态、鼠标检查目标、选中集与键盘输入焦点分别管理。

| 当前状态 | 意图与条件 | 结果 |
| --- | --- | --- |
| Focus：专注胶囊 | 鼠标越过胶囊外侧安全带并停留，且没有保护条件 | 连续拉远至 Peek，显露当前主题、祖先及直接关联邻域 |
| Focus | 点击“查看邻域”或“概览” | 分别进入 Peek 或 Overview，按钮入口始终可见 |
| Peek：邻域预览 | 鼠标回到胶囊内部并停留，尚未开始图操作 | 连续回到 Focus |
| Peek | 点击图空白、“保持概览”或开始平移／框选／连线／图缩放 | 锁定 Overview，鼠标返回胶囊不再自动放大 |
| Overview：稳定概览 | 点击当前主题的“继续对话” | 回到 Focus，恢复原阅读锚点与编辑状态 |
| 任意状态 | 显式打开另一主题或激活列表项 | 按 INT-004 flush，成功后切换活动 ID 并聚焦该主题；失败保留原输入与活动对象 |

移出边界是镜头探索信号，不导航、不发送、不自动切换主题。节点 hover／关系检查仅改变检查态，不激活节点；胶囊边界停留则按本表改变镜头，必要时按 CODE-011 有界加载邻域。两者都不创建领域对象或发送模型请求。Overview 点击空白不清草稿，后台 run 仍按 INT-008 独立归属。

### 输入与动作保护

- 中文 IME、最近打字、正文选区拖动、拖动滚动条、按钮按下、连线／框选／划删捕获、模态打开及当前不可中断提交期间冻结自动镜头。后台流式生成本身不冻结整片画布。
- 冻结期不累计离开倒计时；条件解除后重新满足完整停留条件。正在键入时鼠标停在外面也不会突然拉远。
- 三种状态转换保持同一个活动编辑器实例、值、焦点、caret、IME 和阅读锚点；镜头变化不触发 blur、卸载重建输入、flush 草稿或写入工作区 revision。
- 输入仍有焦点时，Peek／Overview 保留可读的活动输入托盘并点名目标主题；真实编辑器在屏幕层连续定位，不复制输入。显式选择工具按钮允许正常焦点转移，草稿保留。
- 鼠标可关闭“移出自动展开”或开启“锁定专注”；显式邻域／概览按钮保留，无 hover 设备使用相同入口。
- 新意图从当前镜头位置平滑转向新目标，不排队播放历史动画；时长、回差及输入保护数值见 VIS-014。

### 探索稳定性

- 默认展示有界邻域或上次有效镜头，超出预算聚合；搜索可定位未加载主题，节点的折叠、待加载与生成状态可理解。
- 空白立即拖动平移，长按框选按 INT-015 仲裁；正文滚轮只滚正文，到头也不传递为图缩放。图空白普通滚轮围绕指针缩放，浏览器 Ctrl／Meta+滚轮保持页面缩放；图缩放另有按钮和双指捏合，输入／浮层滚动归所属容器。
- “展开子讨论”查询已存在节点；“展开讨论”是 INT-006 创建动作。展开显示加载／重试，收起只隐藏后代，不丢数据、草稿或 run，未加载后代不冒称不存在。
- 活动主题及键盘焦点路径优先保留。主动收起其祖先时保留活动路径例外并说明，直到显式切换。
- 新消息只更新胶囊内部，分页保留阅读位置；后台完成和局部加载不重排全图或自动 fit。聚焦当前、回到所属根、概览分别命名，邻域弱化不损害可读性。

验收：QA-010。

## INT-016 · 主线轮次与子节点临时预览（MUST，新增）

### 语义定义

- **主线不是单个主节点**：同一主题的每轮问答完成后追加一个新的主线节点；旧轮次保留，节点按 `parent` 边串联，形成有序主线序列。
- **当前主线焦点**：默认是主线序列的最新节点；打开它显示当前主题的完整对话胶囊，输入框和草稿仍绑定当前活动主题。
- **子节点**：不属于当前主线焦点的可探索节点，包括主线历史轮次、独立子讨论及其他已投影主题。子节点的空间位置和领域 ID 不因悬停改变。
- 主线节点追加是服务端真实轮次结果，不由前端每次渲染临时生成；未完成、失败或取消的回答不能伪装成新的主线轮次节点。

### 悬停预览状态

1. 鼠标进入可交互子节点后，先显示轻量的鼠标跟随提示；停留达到 **5ms** 后才进入完整预览动画。计时以“进入新节点”为起点，同一节点内的微小移动不得重置计时。
2. 预览是临时状态，不改变 `app.branch`、当前活动主题、草稿、输入焦点、运行态或浏览器历史；鼠标悬停不能触发发送、保存、切换或 revision 写入。
3. 子节点进入预览后，子节点平滑移动到主线焦点的视觉位置，并放大到与主线胶囊相同的尺寸、形态和阅读区域；原主线焦点同时缩小到普通子节点级别。这里的“一致”包含外框尺寸、圆角层级、阅读容器比例和视觉焦点，不要求修改节点的领域位置。
4. 主线胶囊在预览期间降低清晰度并隐藏输入框、编辑托盘、工具托盘及其他边缘框；这些控件不得继续接收指针事件。原主线的内容不丢失、不卸载，预览结束后继续使用同一输入实例。
5. 预览内容优先显示子节点自己的完整历史对话。若本地没有对应消息页，允许发起可取消的临时加载请求，并显示明确加载态；鼠标离开、进入另一个节点、打开模态或开始画布手势时取消未完成请求。临时请求的迟到响应不得覆盖当前主题。
6. 鼠标离开子节点和预览胶囊后，预览状态恢复为悬停前的主线焦点；恢复只改变镜头和渲染，不改变领域对象。若用户已经点击提交切换，则不再执行恢复。

### 点击提交状态

- 点击放大的子节点或其卡片，才正式切换当前活动主题；切换前按 INT-004 flush 当前草稿，成功后子节点成为新的当前焦点，输入框和草稿绑定到该主题。
- 点击必须是可发现的等价入口：概览模式下整个主题胶囊可点击，不能要求用户寻找“打开完整对话”按钮。摘要、跟随提示和焦点样式可以说明“点击打开”，但不替代实际命中区域。
- 点击切换失败时保留原主线焦点、原草稿和原输入焦点，并就地提示失败原因；不得把临时预览误报为切换成功。
- 键盘聚焦的节点以 Enter／Space 提交同样的正式切换；没有鼠标的环境不能依赖悬停预览完成任务。

### 画布与手势优先级

| 输入 | 判定 | 结果 |
| --- | --- | --- |
| 左键按下空白并移动超过 8px | 空白画布平移 | 平移整个画布，不进入框选或关联 |
| 左键按下空白并静止达到 350ms 后拖动 | 空白画布框选 | 进入框选预览，释放后确定选择集 |
| 左键按下节点并移动超过 8px | 节点关系拖拽 | 从源节点拖向目标节点，释放后进入关系确认 |
| 左键短按节点 | 节点打开 | 概览中提交正式切换；其他视图打开对应主题 |
| 右键拖动图面达到删除阈值 | 划删预览 | 按 INT-015／INT-005 进入可恢复移除流程 |
| 指针经过控件、胶囊、输入或模态 | 保护区域 | 不穿透到画布，不触发平移、框选、关联或划删 |

悬停计时不能与自动 Peek／Focus 镜头共用计时器；临时预览、自动镜头和真实指针手势必须拥有可区分的状态与取消路径。预览动画不得阻断空白区域左键平移，也不得因为主胶囊缩放而丢失节点或画布的命中关系。

### 反例与验收引用

- 反例：鼠标悬停子节点立即修改当前主题，移开后无法回到原主线；这是正式切换和临时预览混淆。
- 反例：主线每轮只改写同一个节点，导致无法沿 `parent` 链回看轮次；这是主线序列语义丢失。
- 反例：主胶囊在概览中使用 `pointer-events: none`，或依赖“打开完整对话”按钮；这是视觉入口和实际命中不一致。
- 反例：悬停加载的迟到响应覆盖当前草稿；这是可取消请求和活动 ID隔离缺失。
- 验收：QA-010-INT016-01～08，覆盖主线追加顺序、5ms 停留、完整预览加载取消、离开恢复、点击提交、点击失败恢复、空白平移和节点关联。

## INT-013 · 鼠标核心任务、阅读与往返导航（MUST，图形迭代目标）

标准旅程：**找到主题→展开胶囊阅读→选区预览并确认讨论→邻域呈现子分支→探索关联→返回出处→继续原问题**。全程共享活动 ID、草稿与运行态。除文字录入外，以下核心路径无需键盘快捷键；每个手势均有按钮／菜单等价入口。

| 任务 | 主要鼠标路径 | 可发现入口／约束 |
| --- | --- | --- |
| 新建、搜索定位、打开 | 顶栏新建／搜索，点击结果打开 | 有界主题列表、清除搜索；新建防重 |
| 输入、发送、停止、重试 | 点击输入框／发送／停止／重试 | 停止指向对应 run；失败保留问题 |
| 阅读与历史翻页 | 胶囊内滚轮、上一页／下一页 | 生成时提供“回到最新”，不强制追尾 |
| 查看邻域、概览、返回当前／根 | 边缘探索或具名工具按钮 | 锁定专注、自动展开开关、继续对话 |
| 平移、缩放、调整大小 | 图空白拖动／滚轮、加减与比例菜单 | 适配当前邻域、重置比例，无需键盘修饰键 |
| 展开／收起子讨论 | 节点展开控件 | 菜单同名动作，与创建讨论区分 |
| 单选／多选 | 标题选择控件；空白长按后拖框 | 选择模式按钮、逐项点击勾选、清除选择 |
| 关联主题 | 框选后浮动“关联”，指定源再点击目标；或连接柄拖线 | “关联到…”菜单及目标搜索；源／目标／类型预览后提交 |
| 引用、上下文、断开关系 | 选择引用并确认来源范围；点击边检查 | 关系列表点名类型与两端，断开仅处理该关系 |
| 选原文、复制、创建讨论 | 正文左键拖选→工具栏复制／展开讨论 | “选择原文／从这里分叉”菜单，预览后确认 |
| 返回出处与上次阅读 | 出处、面包屑、返回／前进按钮 | 按 ID 加载原页并恢复选区、阅读锚点及镜头 |
| 重命名、收藏、移位 | 节点更多；显式整理模式拖动标题 | 位置预览／取消，仅改坐标 |
| 移除与恢复 | 右键划删→浮窗恢复 | 更多菜单移除、多选移除所选、最近移除列表 |
| 配置、导入导出 | 设置按钮与具名文件操作 | INT-003／009 的确认、取消及部分成功反馈 |

多选“关联”先指定一个主源，再指定一个或多个明确目标，预览将建立的边及类型后确认；不将 N 个主题默认为全连接。联系不进入模型上下文，引用保持方向及范围；自己、聚合、空白或含糊目标不自动吸附提交。

- 切换前遵循 INT-004 flush；失败留在原分支。进入新分支后显示面包屑及出处入口；面包屑代表主树祖先，“返回上次位置”代表访问历史，跨边导航不修改面包屑。
- 导航记录分支 ID、消息／页、origin range、阅读锚点、镜头、view 状态与触发项；保存稳定标识，不保存 DOM Range。返回出处先分页加载源消息，再校验 range 并高亮；来源删除时保留快照并解释失效。
- 浏览器返回／前进与应用导航记录一致；返回不能创建新历史循环、重复建讨论或发送。迟到请求不得覆盖新导航。恢复坐标受当前视口约束，优先使阅读锚点、所选节点和控件可见。
- 宽窄屏采用同画布胶囊连续镜头，响应式变化只约束空间，不重置状态；保留标题、出处、发送、概览与继续对话入口。退出专注不停止后台生成、不删除分支、不丢草稿；页面任务模式不锁 Tab，设置模态仍按 INT-002。

验收：QA-010，并回归 QA-004、QA-005。

## INT-014 · 图形可访问性与只读探索（MUST，图形迭代目标）

- 图提供可访问名称、操作帮助及同步有界列表，列出主树和关系类型／来源；搜索／分页可达未加载项。鼠标任务通过具名操作有键盘等价路径，不把全图塞入隐藏 DOM。
- Tab 进入工具栏、节点集合／列表、当前对话；节点采用 roving focus，方向键按已加载稳定顺序移动，Enter 打开。展开、聚焦、缩放和返回有具名按钮，输入内保留原生编辑键。
- Escape 先取消当前未提交预览，再关闭非模态检查；无临时操作时保留阅读和草稿。窗口失焦、pointercancel、捕获丢失也取消预览；已提交动作转结果核实，不能当成本地取消。
- 提供鼠标可点击的取消动作；模态按 INT-002 约束焦点，非模态概览不锁 Tab。
- 命中目标保持屏幕尺寸，碰撞时聚合或候选选择，同一点不随机命中多个主题。标题全文可经焦点、点击、触摸或列表获得。
- 只读可探索、复制、查看关系及返回出处；创建、关系写入、移位保存和移除说明不可用原因，手势识别器同样执行限制；只读节点仍可聚焦。
- 减少动效、高对比保持同一终态与任务；状态按 INT-001 播报，流文字、镜头及恢复倒计时不逐帧播报。

验收：QA-010。

## INT-015 · 手势、空间整理、连线与恢复（MUST，图形迭代目标）

框选、连线、移位、划删与恢复为核心鼠标能力。阈值唯一见 VIS-014；按下时记录稳定对象及命中快照，识别后捕获指针并冻结自动镜头。选择、取消及预览不产生持久化写入。

| 起点与动作 | 判定结果 |
| --- | --- |
| 正文／输入框左键拖动或长按 | 原生文本选择、caret 与编辑，不进入图框选 |
| 图空白左键立即拖动 | 越过拖动阈值后平移；超过长按抖动范围后本次不再转框选 |
| 图空白左键静止长按，再拖动 | 提示“框选”，矩形与可见主题命中框相交即预选高亮；释放确定选择集，点击浮动“关联”进入源／目标步骤 |
| 节点标题短按 | 打开该主题；独立勾选控件仅选择 |
| 节点标题长按后拖动 | 以该主题为源连线预览；在明确目标释放后显示端点／类型确认 |
| 连接柄左键拖动 | 越过阈值即连线预览，无需长按 |
| 整理模式拖动标题 | 预览空间移动，释放保存、取消复位；模式明确显示并暂时代替标题长按连线 |
| 图空白／标题右键静止释放 | 正常上下文菜单，包含对象适用的移除、关联、复制主题链接等动作 |
| 图表面右键划动 | 达到划删阈值后显示轨迹与候选高亮，释放按单目标规则提交 |
| 输入框／正文／工具栏右键 | 保留原生或控件菜单，不识别图划删；图路径经过这些区域也不穿透命中 |

### 划删单目标与恢复

1. 右键按下仅候选，不删除；达到最小轨迹阈值才识别，轨迹与目标可见。
2. 用相邻采样点线段与可见主题命中形状求交，避免高速漏检；使用稳定 ID 和同一命中快照。标签字形、边、聚合及被浮层遮挡对象不作为删除目标。
3. 锁定轨迹上第一个无歧义真实主题，显示名称及“松开移除，可恢复”。同段多交点按沿路径首次进入距离判断；仍不唯一则提示选择，本次释放不删。
4. 后续划过其他主题仍仅保留首个高亮，不批量删除所有交点。多删须先框选，再用“移除所选”范围预览与确认。
5. 无目标、目标已变更／移除、只读、取消、窗口失焦均不提交。短于阈值释放按右键菜单处理；已识别但无命中只结束预览。
6. contextmenu 抑制仅作用于本次已识别图手势。对按下即打开菜单的宿主，在图表面局部延迟判定，未识别时补回等价菜单；输入菜单保持原生，不全局拦截。宿主无法可靠区分时提供显式“划删模式”，保留菜单移除。
7. 释放提交软移除后按 INT-005 显示 pending、核实结果、成功浮窗与恢复；不以每次强制模态替代可逆反馈。

首次图使用可显示可关闭手势示意，从帮助可再次打开；示意不充当每次操作确认。

### 整理与关系保护

- 连线释放只进入端点／类型确认；联系说明不进 AI 上下文，引用按 INT-006／007 确认出处与范围。空白、自己、目标含糊时取消或选择，不偷偷吸附。
- 移位只改空间坐标；断开联系／移除引用点名类型与两端，只处理该关系，不删主题消息，不重写已发送历史；后续上下文影响按服务端结果说明。
- 自动布局／固定位置为 MAY；采用后重排有预览和取消，固定节点受保护，流式更新不持续重排。
- 主树归属是独立语义命令，须预览由来／上下文影响、确认并服务端校验森林，契约支持后才开放；移动、断线、划擦显示线均不暗改归属。
- 布局／关系撤销点名动作，只补偿对应对象，执行版本冲突检查；失败不报成功，不用全工作区旧快照覆盖后续消息与草稿。

验收：QA-010；投影及手势／恢复契约见 CODE-011、CODE-012。
