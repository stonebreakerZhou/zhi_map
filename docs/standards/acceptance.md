# 验收规范

[规范索引与等级](README.md) · 本页负责怎么验证和何时通过；界面目标引用 VIS，行为引用 INT，数据／代码契约引用 CODE。

原则：同环境可重复、关键路径可操作、数据结果可证明。截图通过、测试退出成功、真实账号成功和桌面安装成功是不同证据，不互相替代。下面新增阈值是规范目标，不是既有测量成绩。

## QA-001 · 执行基准（MUST）

| 基准／变体 | 执行条件与目的 |
| --- | --- |
| 主视觉基准 | Windows、固定版本 Chrome、1440×900 **CSS 视口**、DPR 1、浏览器缩放 100%；记录 OS build、引擎版本和实际字体 |
| 桌面布局变体 | 1920×1080、1024×720、900×600 CSS 视口；验证内容约束、长表单和头尾可达 |
| 窄屏变体 | 390×844；320×568 为下界压力测试目标，不宣称已有该设备支持承诺 |
| 断点边缘 | 宽 699／700／701 CSS px，高 900；按 VIS-005 验证抽屉切换、遮罩与动作可达 |
| 栅格化变体 | DPR 2 单独截图基线，不与 DPR 1 直接比较 |
| 原生缩放 | 实际 Windows 显示缩放 125%／150%／200%，运行真实 WebView2；不能仅用浏览器 deviceScaleFactor 冒充 |
| 原生最小窗口 | 将 pywebview 窗口缩到宿主允许最小值；记录外窗尺寸、`innerWidth/innerHeight`、visualViewport、DPR，按**实际内容区域**操作 |

原生窗口约束见 VIS-005；900×600 CSS 页面测试只是受限小视口测试，不能证明同数值的原生窗口已通过。软键盘、粗指针和触摸须另测真实环境；未测就记“未验证”。每次只在同引擎／字体基线内比较像素，跨引擎比较语义与几何。

## QA-002 · 像素级验证流程（MUST）

1. 固定数据：使用领域 seed 的人工学习示例及固定长标题、中文／英文／emoji／公式／错误文本；固定活动主题、分页位置、选区、草稿、连接状态和 mock 响应。不得用随机生成回答截图。
2. 固定环境：等待 `document.fonts.ready`、目标元素和应用状态就绪；禁用动画、平滑滚动与闪烁 caret；必要的时间／ID 显示固定；不依赖任意 sleep。
3. 记录 computed style：字体、行高、padding、颜色、圆角等 token **精确一致**；颜色归一到同一 RGBA 表示再比，不比较 hex 与 rgb 字符串格式。
4. 记录关键 DOMRect：侧栏、顶栏、阅读列、按钮、输入、模态头尾、工具栏边界。几何目标允许 **±1 CSS px**，仅用于布局舍入，不允许把错误 token 当容差。
5. 截图叠加检查轮廓、文字基线、截断、遮挡与操作可达；文本内容或字体替换造成的差异不可归类为抗锯齿噪声。
6. 留存实际图、期望图、差异图、关键矩形与环境信息；证据放现有 `test-results/` 或任务附件，不另建大量过程文档。

### 自动截图差异的目标政策

现有浏览器脚本会输出截图，**尚未安装／接入截图断言门禁**。未来接入 Playwright 截图比较时，候选参数为 `threshold:0.2`、`maxDiffPixelRatio:0.001`；即感知颜色阈值和整图最多 0.1% 差异像素，不是允许控件整体移动。

这组参数只有在相同环境连续三次重复截图、检查噪声分布后才能批准为该基线阈值。无法稳定到该阈值先排除字体／动画／数据噪声，不能自动放宽。默认零像素差异不适用于字体栅格化；但关键控件几何、文字裁切、焦点可见与颜色断言始终单独通过，不得被整图比例掩盖。

更新基线须附预期变化、VIS ID 与差异审阅；不能运行“更新全部快照”清除未知失败。屏蔽区域仅限明示的非关键动态内容，禁止屏蔽按钮、字段错误或模型状态。

## QA-003 · 对比度与可读性（MUST）

使用浏览器可访问性检查或按 WCAG 相对亮度计算实际前景／背景对比度，透明色先合成。记录配色组合、比值、角色与结论；VIS token 不是自动合格声明。

- 普通文本至少 **4.5:1**；大文本（至少 24 CSS px，或至少 18.66 CSS px 且粗体）至少 **3:1**。
- 识别交互控件或状态必需的边界、图标、焦点指示与相邻色至少 **3:1**；仅装饰线不强制此比值。
- 禁用控件不按有效操作的对比度规则冒称通过；仍须可辨认，并能理解不可用原因。
- 覆盖默认、hover、active、focus、错误、选中、禁用和叠层实际背景；包含 placeholder、辅助说明、通知与危险确认。
- 浏览器文字／页面放大到 200% 验证折行和键盘可达，不能用缩小字号修复。中文标题、混合 URL、长错误、代码与公式都不得制造页面横向溢出。

若对比度失败，修改权威 VIS 配对再验收，不在单个组件偷偷换另一种颜色。

## QA-004 · UI 验证矩阵（MUST）

每行在主基准与相关窄屏变体执行；弹窗、导航、选区另外覆盖断点与原生小窗口。记录“通过／失败／未验证”，不能把计划写成测试成绩。

| 路径 | 输入／故障 | 通过条件 | 规则 |
| --- | --- | --- | --- |
| 设置打开 | 正常、慢加载、失败重试、关闭重开后旧响应返回 | 表单状态准确，旧响应不覆盖新输入，错误可恢复 | INT-003 |
| 模型保存 | 空白、非法 URL、整数边界、留空 temperature | 错误字段有名称及说明，首错可定位，合法值可保存 | INT-003、CODE-004 |
| 连接身份 | 切协议、切品牌预设、编辑自定义地址 | 密钥先清除，自定义／预设行为准确，无旧密钥外发 | INT-003 |
| 保存并测试 | 保存失败；保存成功但测试失败 | 两阶段反馈可区分，重新加载显示正确持久状态 | INT-003 |
| 清配置 | 有／无服务器 fallback，带 dirty 修改 | 确认范围准确，生效状态刷新，会话消息不变 | INT-003 |
| 弹窗 | 长设置、长错误、dirty Escape、嵌套确认 | 头尾可达、正文滚动、输入不丢、焦点返回 | VIS-007、INT-002 |
| 导航新建 | 快速连点、空默认主题、窄屏 | 不重复创建，新任务聚焦输入、导航收起 | INT-004 |
| 更多整理 | 当前 A，操作 B；中文 IME 重命名 | 只修改 B，组词 Enter 不提交 | INT-004 |
| 删除 | 当前分支 revision 撤销、目标逐操作恢复、无关草稿保存、会话主线永久删除 | 分别按当前契约与实施目标验证；新恢复不因无关写入失效，旧入口不冒充新能力；范围、期限及独立子分支保留正确 | INT-005、CODE-012、QA-010 |
| 选区 | 鼠标、键盘、emoji、公式原文、跨消息 | 精确片段；无效选择不退化；整条分叉先预览 | INT-006 |
| 工具栏 | 顶／底／左右边缘、滚动、resize、粗指针 | 在可视边界内，操作不丢选区，不意外滚到底 | VIS-008、INT-006 |
| 复制 | 允许／拒绝剪贴板权限 | 实际文本完全相同；拒绝时有可行替代且不报成功 | INT-006 |
| 引用分页 | 跨页勾选、切来源、非法范围、来源删除 | 选择按规则保留／清空；返回原文或解释失效 | INT-007 |
| 加载状态 | 无数据、无搜索结果、请求失败、消息翻页 | 各状态可区分、可重试、不误操作旧页 | INT-001、INT-007 |
| 键盘全流程 | 仅 Tab／Shift+Tab／Enter／Escape | 无焦点陷阱或隐藏焦点，命名完整，关键路径可完成 | INT-010 |
| 减少动效 | reduced-motion 与正常模式 | 状态结果相同，减少动效模式无位移／平滑滚动 | VIS-009 |

## QA-005 · 数据与流故障矩阵（MUST）

| 场景 | 通过条件 |
| --- | --- |
| 草稿 flush 失败／revision 冲突 | 当前输入保留；不切换、不覆盖；提示可重试 |
| 后台分支完成、迟到分页／旧 run | 不改变前台主题或草稿；无重复回答；非法事件拒绝 |
| 三种协议模拟 | 各自真实事件结构、分片 UTF-8、usage、正常终态均正确归一 |
| 超时、截断、过滤、上游错误、EOF | 不保存为成功回答；问题保留；错误脱敏、可重试 |
| 取消和终态竞态 | 正确 run 释放资源；同一回答最多保存一次；最终 UI 与 DB 一致 |
| 上下文裁剪／必需内容超限 | 裁剪明示，选区与最新问题保留；无法保留时拒绝生成 |
| UTF-16 边界 | emoji、中文、混合换行精确往返；代理对中间位置拒绝 |
| owner／来源／revision 伪造 | 请求拒绝，其他工作区及当前数据无部分写入 |
| 导入损坏、超限、取消、磁盘故障 | 原工作区保留；staging 清理；提交后刷新失败不误报回滚 |
| 密钥与恶意内容 | API／导出／日志／截图无真实 key；渲染不执行脚本 |

模拟测试与真实厂商账号分开：当前仓库使用协议 fixture，尚无真实账号验证结论。发布声称支持某账号／模型时，应另记录协议、模型名、时间、脱敏请求结果与取消表现；不能以兼容预设存在证明真实服务成功。

## QA-006 · 性能与规模基准（MUST）

复用现有 `browser_smoke_runner.mjs` 的 **100 主题／10000 消息**短文本 NDJSON fixture，以及 `test_paged_workspace.py` 的单分支大历史场景。固定生成文本和随机性；额外大正文 fixture 单独标记，不与短文本成绩混合。

| 指标 | 验证方法／通过条件 |
| --- | --- |
| DOM 与缓存 | 连续翻页及切换主题后按 CODE-005 上限断言；不统计临时 stream 为持久消息行；无全量 snapshot 请求 |
| 普通网络响应 | 在上述短文本 fixture 上，普通 workspace view／branch／entries／compact 响应的解压后 UTF-8 body **≤64 KiB** 为新增目标；排除 SSE、备份文件与单独大元数据 fixture，但必须列出排除的端点与原因 |
| 当前脚本差距 | 现有 browser smoke 普通响应阈值是 **100000 字节**；不能把其通过当作新目标已通过，单次较小响应也不是通用上限 |
| 页面交互延迟 | 建议初始目标：点击至 loading 可见 p95 ≤100ms；本地翻页／切主题至内容可操作 p95 ≤300ms；均为待实测目标 |
| 延迟采样 | 固定机器、电源模式、数据库、无外网模型；预热 5 次、采样 30 次；记录 CPU／内存／引擎和原始样本，冷启动另报 |
| 字节／内存 | 同时记录响应字节、缓存条数及进程峰值；超大单记录另测。仅条数通过不能宣称 RSS 恒定或 TB 规模可用 |

延迟指标须先建立首轮实测基线，之后同环境不得较获批基线退化超过 20%，且应满足目标；未达标记录问题与适用发布判断，不伪造已有成绩。导入、复制、模型首字延迟分开测，不能纳入本地翻页指标。

## QA-007 · Windows 分发验证（MUST，发布桌面产物时）

1. 核对本次构建 ID、manifest、ZIP／EXE hash；确认产物来自本次构建。目录中历史 Setup 文件不证明本次生成了安装器。
2. ZIP 解压到仓库外中文及空格路径，保留完整 `_internal`；清除开发 PYTHONPATH／干扰环境，以隔离 LOCALAPPDATA 启动真实 EXE。
3. 实际 WebView2 验证窗口、页面加载、模型配置加密、新建主题、重启后身份／数据持久化，并保存原生窗口截图及日志。
4. 原生最小窗口及 Windows 缩放按 QA-001 实测；浏览器截图不能替代。
5. 安装包在干净 Windows 用户／虚拟机执行安装→启动→升级→卸载；分别检查运行时已存在／缺失及包内是否含引导程序的真实分支，不声称离线必定自动安装运行时。
6. 核对安装文件与对应构建清单；卸载后用户数据目录保持完整。验证使用隔离测试数据；真实用户 profile 不启动、不修改，可选只读检查须明确启用。

现有 packaged smoke 验 ZIP／真实 WebView2，**不是完整安装器验证**；安装器与原生缩放仍需对应独立证据。环境阻断记录具体阶段，不能写成通过。

## QA-008 · 当前命令与工具地图（MUST）

下列命令均在仓库根目录执行，Windows 使用 `py`；其他系统替换相应 Python 解释器。依赖按现有 README 预先准备。此处列入口，不表示本次文档修改已执行应用测试。

| 已有入口 | 用途／前置条件 |
| --- | --- |
| `npm run typecheck` | TypeScript 构建式类型检查；不是 ESLint |
| `npm run build` | Web 生产构建；不等于行为测试 |
| `npm test` | `py -m pytest backend/tests -q`；需要 backend test extra |
| `npm run test:browser` | 构建 Web、临时 SQLite／FastAPI、Chrome 真实浏览器；需要 Chrome 或 `CHROME_PATH`，调用现有 playwright-core |

`scripts/` 当前为空，不杜撰其验证入口。浏览器脚本包含 `browser_ux.mjs` 场景，输出 `test-results/browser-smoke.png` 与 `ux-*.png`；测试数量随代码变化，不写死为门禁。

**计划工具，非现有命令**：ESLint、Prettier、mypy、按 CODE-003 配置的 Ruff format 检查、截图差异断言、CI 自动门禁。Ruff 在 test extra 中已有声明，但没有本文目标格式配置和 npm lint 入口。接入前不得报告“lint／format／视觉 CI 已绿”。

按改动选择检查：纯文档检查链接、ID、差距和 diff；视觉／交互改动跑类型、构建、相关浏览器矩阵；协议／存储改动跑后端及相关端到端；桌面发布执行桌面与分发验证。一次通过后仅因新改动或未解问题重复检查。

## QA-009 · 严重度与发布门禁（MUST）

| 等级 | 可判定例子 | 处置 |
| --- | --- | --- |
| P0 | 密钥泄露、跨 owner 访问、不可恢复误删／损坏 | 阻断发布，修复并验证影响范围 |
| P1 | 主流程无法完成、错对象操作、输入丢失、取消报成功、确认／发送按钮不可达、关键字段／危险范围被裁切、键盘无法退出模态 | 阻断本次交付，相关路径回归通过后解除 |
| P2 | 不影响任务但违反目标 token、局部对齐、可恢复辅助反馈缺失 | 新增或本次触及的 MUST 不符合项先修复；既有未触及迁移差距可注明范围、负责人及后续任务 |
| P3 | 无功能影响的 SHOULD 改善、措辞／装饰细节建议 | 记录后排期，不冒充 MUST 已符合 |

通过条件：适用矩阵全部有结果；无未解决 P0／P1；新增及触及的 MUST 通过；旧差距明确而不扩散；相关命令退出成功；新增截图基线已审阅；发布产物与实测构建一致。未执行项必须标“未验证”，关键发布路径未验证不得按通过放行。

### 每次变更的简短检查单

- [ ] 适用 VIS／INT／CODE／QA ID、目标状态与旧差距已列明。
- [ ] 正常、加载、空、失败、取消、重试、并发路径有相应结果。
- [ ] 主基准及相关窄屏／断点／原生变体完成，字体和环境有记录。
- [ ] 关键几何、对比度、键盘和对象正确性通过，截图未掩盖问题。
- [ ] 对应命令及证据路径可复核；没有把计划工具写成已通过检查。
- [ ] diff 仅含目标文件；依赖／迁移／文档与实现相符，无敏感数据。
- [ ] 桌面发布核对当前构建、安装器与 ZIP 的独立证据。

记录可直接放原任务／PR：`范围与ID｜环境｜命令及退出结果｜矩阵结果｜证据路径｜未解决问题及负责人｜是否可交付`。

## QA-010 · 连续星空树与鼠标闭环验收（MUST，实施图形迭代时）

本节为未来实施计划，图视图、手势、查询和恢复契约未实现或未验证时如实记录，不以文档目标作为成绩。框选、关联、移位、划删恢复及其按钮等价路径是必须项；自动布局／固定位置为 MAY，未采用注明不适用。QA-001～QA-009 的环境、对比度、非图任务、故障与发布规则继续适用。

### 连续镜头与可读性（INT-011～INT-013、VIS-011～VIS-014）

| 场景 | 通过条件 |
| --- | --- |
| 专注进入 | 按实际 U 测胶囊占比与边缘；编辑器、出处、发送可达，浏览器未被强制全屏 |
| Focus→Peek→Focus | 按 VIS-014 边缘停留触发连续转场；快速划过、边缘抖动、窗口外移动、动画扫过静止指针不误触 |
| Peek→Overview | 点击空白／保持概览或开始图操作后保持概览；回到胶囊上方不自动放大，显式继续对话才返回 |

### 划删、故障与恢复（INT-005、INT-015、VIS-014、CODE-012）

| 场景 | 通过条件 |
| --- | --- |
| 右键菜单 | 静止、微抖及短轨迹正常菜单；输入／正文原生菜单保留，Chrome／WebView2 各测真实事件顺序 |
| 单主题划删 | 阈值前无删除；识别后轨迹、名称和目标高亮，释放才发命令，不强制每次模态确认 |
| 高速跨越 | 线段求交命中高速划过目标，以首个无歧义对象为唯一目标；重复跨过不重复删除，其他交点不连带删除 |
| 遮挡与歧义 | 重叠候选、浮层、标签字形、关系线、聚合及离屏对象不误删；无法唯一判定不提交 |
| 显式多删 | 框选→移除所选→名称／数量／范围→确认，原子提交；取消无副作用，子分支不隐式列入 |
| 指针取消 | Escape、取消按钮、失焦、pointercancel、capture loss 均清预览；未提交无写入，已提交核实结果，不误报取消 |
| 延迟／失败／未知 | pending 无成功浮窗，失败恢复节点及输入并可重试；未知结果用同 operation ID 查询，不重复删除 |
| 草稿与运行态 | dirty 快照保护，保存失败阻止移除；与 completed／cancelled 竞态不丢已确认消息，其他 run 正常，恢复不重启生成 |
| 根与子分支 | 移除根保留独立子分支及快照；最后主题移除进入可新建空状态；恢复不抢当前阅读焦点 |
| 浮窗恢复 | 持久确认后才显示“已移除…恢复”，近目标定位并避让输入／发送；平移、选择和聚焦不让恢复入口消失 |
| 连续移除／刷新 | 单浮窗及最近移除数量准确，关浮窗后列表可恢复；刷新可读取，重复恢复幂等 |
| 无关后续写入 | 删除 A 后编辑 B、发送并完成 B、阅读／分页，再恢复 A；不因无关 workspace revision 拒绝或回滚 B |
| 依赖冲突 | 父节点被删、子分支改归属、ID 占用时返回具体冲突，不覆盖新状态、不消耗未过期记录；降级恢复先预览确认 |
| 期限与授权 | 服务器到期前、恰到期、到期后及客户端时钟偏差均测；到期行为准确，跨 owner 查询／恢复拒绝且无部分写入 |
| 当前旧撤销与目标隔离 | 现有 next-mutation undo 按实际限制标示；新菜单／手势只接逐操作恢复，无关草稿写入不使新入口失效 |
| 永久删除隔离 | 仅独立会话危险动作可永久删除，点名并确认；右键划删不能触发永久删除 |

### 大图和手感性能

在 QA-006 消息规模之外，新增待建设固定 fixture：10000 个主题／讨论节点，含多根、深链、高扇出、孤立组件及跨边环，固定 ID、标题、边和布局种子。另测长标题、大正文、长对话及后台流式；总规模不等于全量挂载。

1. 概览→搜索末端主题→展开→胶囊阅读→Peek→框选关联→取消→划删恢复→连续平移缩放。断言 CODE-011 响应字节、挂载对象／标签／摘录及缓存上限；记录聚合数量、请求身份和内存峰值，无全量 snapshot 或全量正文请求。
2. 记录写请求和工作区 revision：选择、平移、镜头、LOD、收起及取消预览不产生业务写入；关系、位置及移除只在明确提交时写入。
3. 固定机器、电源、引擎，按 QA-006 预热／采样；60Hz 下连续镜头帧间隔 **p95 ≤16.7ms** 为统一初始流畅目标，另报 >33.4ms 帧比例和最长帧。标明 RAF 间隔或 trace 呈现帧的取样方式、精度及原始数据，不能用处理函数耗时冒充呈现帧间隔。
4. 指针动作到首个视觉反馈 **p95 ≤50ms**，镜头中断后的新反馈同样适用。图激活至 loading、局部导航至可操作沿用 QA-006 延迟目标；分开记录网络等待、布局及绘制，不能把慢请求混成动效时间。
5. 受控慢响应、旧窗口晚到、取消后返回、新 revision 及并发流只允许当前有效查询影响视图；已有镜头可操作，未加载邻域有占位／重试。不能通过隐藏活动输入、缩小必要字体或拉取全量正文达标。
6. 几何记录 world 坐标、camera、scale、CSS 投影、DPR 及页面缩放；动效用 trace／录像，静态截图按 QA-002。Canvas／SVG 命中框与语义列表交叉核对，未加载节点经搜索／分页可达。

图响应使用 CODE-011 专用预算，实施时登记具体端点；胶囊阅读调用的既有分页端点仍受 QA-006 约束。自动化入口随实施接入 QA-008，当前不杜撰 graph／gesture 命令。性能均为目标而非已有成绩，未达标如实记录并按 QA-009 判断。

纯规范检查核对五份权威文件的链接、稳定 ID、唯一数值来源、状态／输入保护、鼠标入口、恢复契约及当前事实与目标区分；文档更新不等于应用检查通过。
